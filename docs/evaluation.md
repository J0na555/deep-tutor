# Evaluation Metrics

## Learning Metrics

- reduced repeated mistakes
- reduced hint dependency
- increased independent solves
- concept mastery growth

---

## Behavioral Metrics

- debugging attempts before asking for help
- reflection completion rate
- time spent thinking before hints

---

## System Metrics

- response latency
- routing accuracy
- memory retrieval relevance

## Success Criteria

The system succeeds if users:
- rely less on direct solutions
- solve more problems independently
- retain concepts longer
- improve debugging confidence

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## Initial Target Thresholds

- reduce repeated mistakes by >=20% over 4 weeks
- increase independent solves by >=25% over 4 weeks
- reduce average hint level used by >=1 level over 4 weeks
- maintain routing accuracy >=85%
- keep p95 response latency <=4 seconds on local setup
